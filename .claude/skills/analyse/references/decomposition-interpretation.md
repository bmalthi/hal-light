# Decomposition interpretation

A decomposition allocates a difference under chosen definitions and assumptions.
Its arithmetic can reconcile while its interpretation remains misleading. Select
the method for the question; this guidance does not require a particular formula,
ordering scheme, or helper.

## Make the allocation interpretable

State the population, grouping, weight basis, and consequential allocation choices
alongside the result. For a mix-versus-within split, name the group definitions and
weights beside the numbers, including in charts and tables. “Within group” means
within those particular groups; it does not necessarily hold every relevant
characteristic constant.

Explain how the chosen method handles groups present in only one period, sparse or
missing groups, and any unallocated remainder when these affect the answer. Keep
their effect visible instead of silently dropping them from the explained total.
If sequential allocation or interactions matter, state the convention used.

## Check sensitivity that could change the interpretation

Consider a plausible alternative grouping, weighting, or allocation order when it
could materially change the claimed drivers. Run the discriminating comparison
when the data supports it; report whether the conclusion changes. If the relevant
alternative cannot be evaluated, identify the limitation. If different weights
change the target quantity, label that as a different question. An exhaustive sweep
is unnecessary, and not every method is order-sensitive.

Reconciliation checks the accounting identity. It does not establish that a
component is a causal effect or that the allocation is unique. Calibrate the wording
to what the analysis identifies.

**Example:** A conversion split using acquisition channel alone can count a shift
toward new customers inside each channel as “within-channel change.” Using channel
and customer tenure may classify some of it as mix instead. The total change is the
same; the grouping changes what each component means. Finer groups also need enough
support to make the comparison useful.
