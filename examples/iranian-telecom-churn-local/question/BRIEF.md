# Iranian Telecom Churn

You are advising a telecom operator on retention targeting.

## Questions

- Profile churn by complaints, call failures, subscription length, usage, tariff plan, status, age, and customer value.
- Build a churn model or scorecard and evaluate it under a budget-constrained retention campaign.
- Recommend which customers should receive an offer, service intervention, or no action, using customer value and likely false positives.
- Explain what evidence would be needed to prove retention actions create incremental lift.

## Expected Deliverable

A notebook or memo with churn diagnostics, targeting metrics, and a retention policy.
